# Financial reporting review checklist

Complete one record for each required award financial report. This checklist supports preparation and review. It is not an SF-425 form or a submission system.

Award ID: ______  Form or system: ______  Period: ______  Due date: ______  Basis: ______

| Review item | Status | Evidence or explanation |
| --- | --- | --- |
| Confirm applicable form, instructions, award terms, and due date | | |
| Verify report identifiers and period | | |
| Establish the required cash or accrual basis and reconcile any conversion | | |
| Reconcile reported expenditures to the ledger and supported adjustments | | |
| Review cash receipts and disbursements separately where required | | |
| Support unliquidated obligations and exclude amounts already expended | | |
| Review indirect costs, program income, and nonfederal share where applicable | | |
| Explain relevant differences from previous reports | | |
| Obtain required review and authorized certification | | |
| Retain submission confirmation and any subsequent correction | | |

Status choices: Complete, Open, or Not applicable. Explain Not applicable items. Use the actual award deadline. Distinguish recipient and subrecipient final-report requirements. This template does not automatically calculate deadlines.
