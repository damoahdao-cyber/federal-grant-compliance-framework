# Award register template

Create one record per award. Retain funding amendments and source documents. Link this record to the workbook's Portfolio row through the same internal award ID.

| Field | Enter value | Source or review evidence |
| --- | --- | --- |
| Internal award ID | | Accounting project record |
| Federal agency | | Award notice |
| Assistance Listing title and number | | Verified award or program information |
| Federal award identification number (FAIN) | | Award notice |
| Federal award issuance year | | Award notice |
| Direct or pass-through award | | Agreement |
| Pass-through entity and assigned identifier, if applicable | | Subaward agreement |
| Project or program title | | Agreement |
| Period of performance start and end | | Current agreement and extensions |
| Budget period start and end | | Approved budget |
| Authorized federal funding and amendment history | | Funding notices. Exclude unfunded options. |
| Nonfederal share or cost-sharing requirement | | Approved award terms. Track separately. |
| Accounting basis and ledger project code | | Accounting policy and ledger |
| Indirect rate, base, applicable dates, and supporting agreement | | Rate agreement, applicable election, and award limits |
| Payment method and requesting system | | Award terms |
| Financial and performance reporting deadlines | | Award terms and agency instructions |
| Financial and program owners | | Internal assignment |
| Budget revisions and required approvals | | Dated written approvals |
| Source-record location | | Retained electronic folder |
| Preparer, reviewer, and review date | | Sign-off |

Use source-backed identifiers and amounts. Archive superseded funding records rather than overwriting their history. Record a review cutoff alongside portfolio balances.

Source: [2 CFR 200.302(b)(1)-(3)](https://www.ecfr.gov/current/title-2/section-200.302). The financial management requirements address award identification and records of federal authorizations, obligations, balances, and expenditures. This template adds workflow fields for internal review.
