# Domain 2 regulatory source and applicability register

Reviewed for drafting: October 13, 2026. These are reference entry points, not a complete or certified mapping. The maintainer must verify current text and the rules incorporated into the specific award before marking any item applicable.

| Topic | Primary source | What to verify at award level |
| --- | --- | --- |
| Allowability | [2 CFR 200.403](https://www.ecfr.gov/current/title-2/section-200.403) | Cost principles and exceptions, terms, regulatory version |
| Reasonableness | [2 CFR 200.404](https://www.ecfr.gov/current/title-2/section-200.404) | Ordinary and prudent context and relevant documentation |
| Allocability | [2 CFR 200.405](https://www.ecfr.gov/current/title-2/section-200.405) | Relative benefit, cost shifting restrictions |
| Credits and approvals | [2 CFR 200.406](https://www.ecfr.gov/current/title-2/section-200.406), [200.407](https://www.ecfr.gov/current/title-2/section-200.407) | Applicable credits, any required prior written approval |
| Procurement | [2 CFR 200.317](https://www.ecfr.gov/current/title-2/section-200.317) through [200.327](https://www.ecfr.gov/current/title-2/section-200.327) | Entity type, thresholds, competition, contract clauses, conditions |
| Federal acquisition thresholds | [Acquisition.gov threshold changes](https://www.acquisition.gov/threshold-changes) | Threshold effective date, entity policy, agency and award specifics |
| Compensation | [2 CFR 200.430](https://www.ecfr.gov/current/title-2/section-200.430) | Total activity support, special rules, payroll controls |
| Fringe benefits | [2 CFR 200.431](https://www.ecfr.gov/current/title-2/section-200.431) | Consistency, allocation and approval |
| Travel | [2 CFR 200.475](https://www.ecfr.gov/current/title-2/section-200.475) | Written travel policy, method, special restrictions |
| Conflict reporting | [2 CFR 200.112](https://www.ecfr.gov/current/title-2/section-200.112) | Agency/pass-through disclosure policy |
| Procurement conflicts | [2 CFR 200.318(c)](https://www.ecfr.gov/current/title-2/section-200.318) | Individual/organizational conflicts, recusal, conduct policy |
| Internal controls | [2 CFR 200.303](https://www.ecfr.gov/current/title-2/section-200.303) | Appropriate documented controls, oversight |
| Retention | [2 CFR 200.334](https://www.ecfr.gov/current/title-2/section-200.334) | Applicable start event, exceptions, holds |
| Access to records | [2 CFR 200.337](https://www.ecfr.gov/current/title-2/section-200.337) | Access rights, permitted confidentiality restrictions |
