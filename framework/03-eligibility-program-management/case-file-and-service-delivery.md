# Controlled case file and service-delivery documentation

## Scope
Use for awards that require documenting individual service or benefit eligibility and completed program activities. Other federal awards should apply only those steps relevant to their approved scope. This is a file organization guide, not a system of record.

## Folder or record categories
1. **Rule set:** dated authorized version of eligibility rules and program definitions.
2. **Intake record:** pseudonymous case number, date, request or enrollment type, consent or notice records if required by program law, and secure pointer to source documents.
3. **Eligibility decision:** rules evaluated, dated status, authorizer, evidence references, appeal and correction history.
4. **Activity record:** approved service type, delivery date, staff or provider reference, units, participant acknowledgement where required, and exception notes.
5. **Reconciliation and monitoring:** cross-check activity logs to reported counts, authorized participant lists, and financial records where applicable; document duplicates and reversals.
6. **Retention and access:** approved repository or case management system, access owner, applicable retention trigger, audit trail and any preservation hold.

## Quality checks
- Use one stable activity identifier per record; distinguish service delivery from planned service and cancelled service.
- Reject duplicate units or document legitimate repeats according to program definitions.
- Trace a reported service back to an approved activity, decision record when applicable, and documented delivery.
- Confirm which services can be delivered while eligibility remains pending; never assume all programs permit or prohibit it.
- Correct records by a dated, attributable adjustment, not by destroying the original entry.
- Retain only the information necessary to meet applicable program and reporting requirements.
